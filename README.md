# 국토정보위성 자동 처리 시스템 v2.0 (CAS500-1 L3A Processor)

국토정보위성(CAS500-1 / 국토위성 1호) L3A 데이터를 자동으로 지리보정(Korea 2000 / EPSG:5179)하고, RGB 합성 및 NDVI 식생지수 분석 리포트를 생성하는 도구입니다.

실습실 및 타 컴퓨터에서 복잡한 설치 과정 없이 바로 구동될 수 있도록 **스마트 환경 감지 런처**가 내장되어 있습니다.

---

## 🚀 빠른 실행 방법

### 1. 실습용 컴퓨터 (QGIS가 설치된 PC)
1. 이 폴더 전체를 원하는 위치에 복사합니다.
2. **`run.bat`** 파일을 더블 클릭합니다.
   * `run.bat`가 PC에 설치된 QGIS 내장 파이썬/GDAL 환경을 자동으로 감지하여 **추가 설치 없이 즉시 실행**됩니다.

### 2. 일반 컴퓨터 (QGIS가 없는 PC)
* 파이썬과 GDAL이 설치되어 있다면 `run.bat` 더블 클릭 시 자동으로 파이썬을 찾아 실행됩니다.
* Conda 환경(`komp`)이 구축되어 있는 경우에도 자동으로 연동됩니다.

---

## 📁 주요 기능

1. **GCP 기반 지리보정**:
   * `*_Aux.xml` 메타데이터의 모서리 경위도 좌표를 바탕으로 한국 국가 표준좌표계(Korea 2000 / EPSG:5179)로 정확하게 변환합니다.
2. **RGB 트루 컬러 합성**:
   * Red, Green, Blue 단일밴드를 병합하여 16비트 고품질 RGB GeoTIFF 이미지를 생성합니다.
3. **NDVI 계산 및 안전한 NoData 마스킹**:
   * 식생지수 `(NIR - Red) / (NIR + Red)`를 계산하고, 유효하지 않은 배경 영역은 표준 NoDataValue(`-9999.0`)로 투명 처리합니다.
4. **HTML 분석 보고서 및 퀵룩 생성**:
   * 식생 밀집도 구간별 픽셀 수 및 비율 통계, 분위수, 퀵룩 프리뷰가 포함된 독립형 HTML 리포트를 자동 생성합니다.
5. **다중 씬(Scene) 모자이크**:
   * 동일 촬영일자 또는 여러 씬의 단일밴드를 결합하여 광역 모자이크 래스터를 산출합니다.

## 📂 폴더 구조

```
KompsatProcessor_v2/
├── run.bat            # 스마트 실행 런처 (더블 클릭 실행)
├── requirements.txt   # 라이브러리 목록
├── README.md          # 사용 가이드
└── src/               # 소스 코드
    ├── gui.py         # 데스크톱 GUI (Thread-Safe 아키텍처)
    ├── processor.py   # GDAL 위성 처리 엔진
    └── settings.ini   # 사용자 설정 파일 (QGIS 경로 등)
```

## ⚠️ 문제 해결

* **실행 시 검은 창이 떴다가 꺼지는 경우**:
  * QGIS 또는 GDAL이 설치되어 있는지 확인하세요.
  * 콘솔 창에서 에러 원인을 바로 확인할 수 있도록 `run.bat` 끝에 일시정지(`pause`)가 설정되어 있습니다.
